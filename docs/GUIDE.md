# Judge guide

Start with the [browser demo on GitLab Pages](https://showcase-700ee4.gitlab.io), with no install or credentials. Sign the demo orders, approve the fallback, review the automatic checkout change and read the morning brief, then replay without signing. The two paths make the human boundary visible. The [five gallery images](images/gallery/) show the same night, and the [local instructions](../README.md#try-one-night-in-the-browser) reproduce it.

The browser is a **guided replay** with a simulated shop, planted faults and recorded model replies. The existing Watch code makes the decisions and writes the ledger. The controls choose isolated demo inputs. Separately, the [27 Oct handoff](HANDOFF.md#what-is-live-on-gitlab-today-real-verifiable) records a real [Duo watch-flow session](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43649347/showcase/-/automate/agent-sessions/10120703) that declined because no orders were signed. The newly verified [dusk session](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43649347/showcase/-/automate/agent-sessions/10124688) created [MR !1](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43649347/showcase/-/merge_requests/1): a validated zero-order draft because no verified production change justified an action. [Pipeline 2994232284](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43649347/showcase/-/pipelines/2994232284) passed all 18 jobs for installer sync `e551271`, including 639 application tests with 94% coverage and the Pages deployment. Public Pages playback remains unverified from this restricted environment. The relay has not been deployed to Google Cloud, and no live overnight action has run. See [Status](STATUS.md).

The [official rules](https://gitlab-transcend.devpost.com/rules) name five equally weighted criteria, so each has **20%** of the score before any cloud bonus. The primary-source extracts are in [Rules check](codex/RULES_CHECK.md#judging-stages-criteria-and-weights).

For a direct look at the permission code, use **Check the permission boundary** below the browser replay. Inspect the injected action, expired orders and thin-traffic cases, then select **Valid control**. The panel shows 23 refused attempts and one permitted control, each computed by the real decision functions with simulated inputs. Static Pages includes the build's computed results; choosing a case reads that result.

In **The night leaves a memory**, switch between the checkout and inventory incidents. One has a verified recovery; the other has a human-approved fix whose recovery the ledger does not independently verify. Follow the decision chain and download the shift handoff. The same [incident memory](INCIDENT_MEMORY.md) persists across nights in the relay and informs the next dusk briefing, without granting new authority.
