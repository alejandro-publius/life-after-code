## Retrieval limits

All 30 exact YouTube watch URLs were opened with the web tool. Twenty-nine returned "Online fetch throttled". The RedAgent page returned its title and a footer, but no video duration or transcript. No video playback or opening was available.

Official YouTube oEmbed requests for Sankofa, Stayed Shipped and RedAgent also returned "Online fetch throttled". Official embed requests for Sankofa and LORE returned the same error. A direct YouTube oEmbed request through the configured proxy failed with "CONNECT tunnel failed, response 403". The normal proxy and TLS configuration were preserved.

An English timed-text request for RedAgent was also throttled: https://www.youtube.com/api/timedtext?v=9Kb1JsBs7ZM&lang=en. An empty or blocked caption result does not establish that captions do not exist. Exact-ID web searches for Sankofa, Stayed Shipped, Carver, Marshal and RedAgent returned no results.

No maximum duration from the hackathon rules is substituted for an actual video length. No project description is presented as a transcript or as the opening 30 seconds.
