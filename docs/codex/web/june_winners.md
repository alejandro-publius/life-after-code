Sankofa
Source: https://devpost.com/software/sankofa-mcq8af
Builder: Roger Kor.
Description, paraphrased: Three Duo agents produce merge-request impact reports, issue onboarding briefs and vulnerability propagation reports with targeted child issues. The page describes a FastAPI Cloud Run backend using Gemini, and an Orbit fallback through repository static analysis.
Built With: fastapi, gemini, gitlab, orbit.
Video: https://www.youtube.com/watch?v=bsen3A1-v20

Stayed Shipped
Source: https://devpost.com/software/stayed-shipped
Builder: Nick Sawinyh.
Description, paraphrased: Tracks merged changes through survival windows, separates deployment evidence from merge-only evidence, handles contested verdicts, credits repairs and creates digest issues. Its reference engine uses Python's standard library; the deployed Duo flow reimplements the methodology through prompts.
Built With: orbit.
Video: https://www.youtube.com/watch?v=fGcahHfqeuU

Carver - The migration-quoting agent
Source: https://devpost.com/software/carver-the-migration-quoting-agent
Builder: Anes Mulalic.
Description, paraphrased: Quotes migration effort, risk, cost and sequence from dependency data. A flow opens a branch and one merge request with AGENTS.md and MIGRATION.md. The page describes a committed dependency-graph fallback and source-grounded estimates.
Built With: gitlab, javascript, markdown.
Video: https://www.youtube.com/watch?v=MMKtIjuMYhs

Marshal - Autonomous Migration Assistant
Source: https://devpost.com/software/marshal-autonomous-migration-assistant
Builder: Jyothsna Ashok.
Description, paraphrased: Finds a fleet of repositories, orders migration waves, lands issues and actual merge requests, and routes stalled work to named people. Human approvals separate phases. The page identifies OpenRewrite as its working Java engine and several other engines as reference stubs.
Built With: claude, gitlab, openrewrite, python.
Video: https://www.youtube.com/watch?v=TMKUON_rNhU

CrossCut
Source: https://devpost.com/software/crosscut
Builders: Rahul Gunwani, pritesh kumar.
Description, paraphrased: Uses Orbit call relationships and changed symbols to generate a smaller child test pipeline. If it cannot establish a safe narrower selection, it runs the full suite. Its page reports 8 of 78 tests for one example, with a wider 26-test selection for a shared model.
Built With: duckdb, framer, gitlab, mypy, next.js, orbit, pytest, python, pyyaml, react, recharts, rest, tailwindcss, typescript.
Video: https://www.youtube.com/watch?v=i0acwNFepRo
Scope caution: The announcement discusses savings on large or cross-repository suites; this page labels cross-repository support as future work. Do not turn that award rationale into proof of a shipped cross-repository implementation.

OrbitWeaver
Source: https://devpost.com/software/orbitweaver
Builder: Aryan Rajput.
Description, paraphrased: Orders dependent files with Kahn's algorithm, asks a local model for scoped changes, and opens a merge request with a Mermaid dependency diagram. The page reports a 12-file example and identifies multi-repository support and compilation gates as future work.
Built With: kahn's, mcp, mermaid.js, node.js, ollama, qwen, typescript.
Video: https://www.youtube.com/watch?v=uGoyUH04PZk

Transcend
Source: https://devpost.com/software/transcend-q4cpih
Description, paraphrased: Converts Orbit data to OWL and RDF, then uses SPARQL for transitive reasoning and federated joins with external knowledge. The page distinguishes real local code-graph data from a synthetic SDLC fixture and says it lacked a live remote SDLC export.
Built With: gitlab, python.
Video: https://www.youtube.com/watch?v=8r9Rnea0sCY

Universal Agent OS
Source: https://devpost.com/software/universal-agent-os
Builder: Mehmet Aydoğan.
Description, paraphrased: Gives Duo agents an initial interview, persistent context, explicit approval gates and reviewable GitLab artifacts. Its page describes a founder proposing ParkShare, followed by a plan, epic, seven issues and a merge request, with an executable Orbit check for overlapping work.

## Source limits and design implications

The overview shows 1,560 participants while the announcement reports 1,576 registrations. Preserve both reported values without guessing the denominator. Twenty entry awards and nineteen reported cash recipients are different units. Multiple entries can share an author, so the counts alone do not establish a contradiction.

Interpretation for our concept choice, not an official judge requirement: integrate into the developer's existing workflow, show useful work completing, and expose understandable evidence at a decision. A generic survival ledger overlaps Stayed Shipped. Organization-wide migration completion overlaps Marshal. These precedents argue for a more specific user problem and a distinctive result that can be shown live.

Video titles, durations and openings belong in videos.md. Those facts were not verified in this file.
