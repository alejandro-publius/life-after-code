# Stage acceptance and evidence

This map separates **live** GitLab artifacts, **simulated** checks of real code with demo inputs, **configured** capabilities without execution proof, and **blocked** checks. A model reply is not an action. An approval is not measured recovery. A successful local check is not a deployment.
